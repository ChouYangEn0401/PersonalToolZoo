# diff_showcaser

簡單的 Git diff 統計 GUI 工具。

用法：

- 在專案根目錄下執行（必須是 git 倉庫）

```
python -m diff_showcaser
```

視窗分成兩個分頁：

- **Git 版控比較**：輸入 `init_commit` 與 `latest_commit`（可以是 branch 名稱或 commit hash），按 `Compute`。顯示兩個 commit 之間每種副檔名的新增/刪除行數與位元組差異。
- **資料夾快照（當下統計）**：專案沒有版控時使用。只選擇「一個」資料夾，工具會直接統計「當下」的狀態——每種副檔名目前的總行數與總大小，不是兩個時間點之間的差異（沒有版控就沒有「之前」可以比較）。想追蹤變化的話，就在不同時間點各執行一次，自行比較兩次結果。

兩個分頁的版面（篩選、分類、表格、可拖曳分隔）完全一致，差別只在於 Git 分頁顯示「變動量」（新增/刪除/淨變動/位元組差異），資料夾分頁顯示「當下總量」（總行數/總大小）。

顯示：
- Git 分頁：每種副檔名的檔案數、加上/刪除行數、淨行數、近似位元組差異（若可得）與範例檔案；上方顯示總共變更的檔案數與總加/刪行數。
- 資料夾分頁：每種副檔名的檔案數、總行數、總大小與範例檔案；上方顯示總檔案數與總行數/總大小。

檔案篩選：
- 副檔名會依類別（Python、C# / .NET、Web 前端、設定/資料、圖片、編譯/執行檔…）分組顯示，每個類別都有「全選／清空」。
- 快速篩選按鈕可一鍵套用預設組合：**代碼統計模式**（只看行數變動有意義的原始碼/文字檔）、**Bytes 檔案統計模式**（只看以位元組大小變動為主的圖片/編譯/壓縮檔等）、全選、清空。
- 每次按下 Compute 後會自動套用「代碼統計模式」作為預設勾選，可再手動調整。

介面：
- 下方「副檔名列表」與「文字摘要」之間可用滑鼠拖曳中間的分隔條調整高度比例，方便截圖摘要區塊。

備註：本工具使用 `git diff --numstat` 與 `git ls-tree -r -l` 來計算，對大型倉庫可能需些時間。
