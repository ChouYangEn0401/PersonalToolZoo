# GUI2 — Quick Converter（快速拖放轉換）

極簡拖放式檔案轉換工具。選好轉換模式後，直接把檔案或資料夾拖進視窗即可在**原檔案旁邊**產生轉換結果，無需設定輸出路徑。

---

## 執行方式

```bash
pip install tkinterdnd2   # 首次需安裝拖放支援
python GUI__QuickConverter.py
```

---

## 功能特色

- **拖放即轉** — 把檔案（或整個資料夾）拖入視窗，自動在原檔案所在目錄產生轉換結果。
- **多規則並行** — 規則列表可加入多條規則，每個檔案會同時套用所有符合的規則。例如：加入「圖片 → PNG」和「圖片 → ICO」，拖入圖片後 PNG 和 ICO 同時輸出。
- **格式自動偵測** — 拖入的檔案若不符合任何規則，立刻彈出對話框顯示該副檔名可用的轉換選項，勾選後執行；並可選擇是否同時加入規則列表以便下次自動套用。
- **批次資料夾處理** — 拖入整個資料夾，資料夾內每種副檔名都會自動比對對應規則分別轉換。
- **檔名衝突處理** —
  - **每次詢問**（預設）：遇到同名檔案時跳出對話框，可選擇覆蓋 / 加後綴 / 跳過。
  - **自動覆蓋**：直接覆蓋同名檔案。
  - **自動加後綴**：在檔名加上隨機後綴保留兩者。
- **深色 / 淺色主題** — 一鍵切換。

## 支援的轉換模式

### 圖片
| 模式 | 說明 |
|---|---|
| 圖片 → PNG / JPEG / BMP / TIFF / WEBP / GIF / TGA / ICO | 單張圖片格式轉換 |
| 圖片 → PDF | 單張圖片轉為 PDF |

### 影片 / 音訊（需 FFmpeg）
| 模式 | 說明 |
|---|---|
| 影片 → MP4 / AVI / MKV / MOV / WEBM / FLV / WMV / TS / GIF | 影片格式轉換 |
| 影片 → MP3 / WAV / FLAC / AAC | 影片提取音訊 |

### 表格
| 模式 | 說明 |
|---|---|
| Excel → CSV | 每個工作表輸出為 `{檔名}.[{工作表}].csv` |
| Excel → Parquet | 每個工作表輸出為 `{檔名}.[{工作表}].parquet` |
| CSV/Parquet → Excel | 合併為 `.xlsx` |

### PDF
| 模式 | 說明 |
|---|---|
| PDF → TXT | 抽取純文字 |
| PDF → DOCX | 轉 Word 文件 |
| PDF → PPTX | 每頁轉為投影片圖片 |

## 使用流程

1. 在「轉換規則」列表中加入想要輸出的格式（可加多條，例如同時加「圖片 → PNG」和「圖片 → ICO」）
2. 設定檔名衝突處理方式（預設為每次詢問）
3. 將檔案或資料夾拖入拖放區域
4. 若有檔案不符合任何規則，自動彈出格式選擇對話框
5. 轉換紀錄會顯示在下方的紀錄區，格式為 `檔名 → 輸出檔名  [規則名稱]`

---

## 注意事項

- 需安裝 `tkinterdnd2` 才能使用拖放功能，否則會顯示提示訊息。
- 輸出檔案一律產生在原始檔案的同一目錄。
- 影片相關轉換需要系統安裝 FFmpeg 並加入 PATH。
