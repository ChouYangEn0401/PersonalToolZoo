# File Renamer

> 用正規表達式規則掃描檔名，把符合的標籤一次換掉；改之前先看預覽，衝突會擋下，改錯了可以復原（關掉程式再開也可以）。

## 功能

- **加入檔案**：按「＋ 加入檔案」「＋ 加入資料夾」，或直接把檔案、資料夾拖進視窗。
  資料夾可以「包含子資料夾」，也可以只加入某些檔案（例如 `*.mp4;*.mkv`）；`.git` 這類隱藏資料夾與 `desktop.ini` 會略過。
- **規則清單（正規表達式）**：一次可以有很多條，**由上往下依序套用**，前一條的結果交給下一條；
  每條可以單獨停用、單獨設定不分大小寫。點一條規則，下方的「尋找／取代成」就是在改那一條，預覽即時更新。
  - 取代成可以用 `$1`、`$2`（或 `\1`、`\2`、`${名稱}`）引用括號裡的內容，`$$` 代表 `$` 本身。
  - 預設**只改主檔名、保留副檔名**，不會把 `.mp4` 改壞；需要時可以選「整個檔名」。
  - 例：`\[(1080p|720p)\]\s*` → 留空（拿掉畫質標籤）；`S(\d+)E(\d+)` → `第$1季第$2集`；`\s+` → `_`。
- **規則組**：把目前的規則存成一組（例如「整理影集檔名」），之後一鍵載入。
- **雜湊改名**（保留副檔名）：檔名雜湊（SHA-256，匿名化）或檔案內容雜湊（內容相同的檔案會得到相同的名字）。
- **預覽會擋下的情況**（標紅、不會套用）：規則寫錯（會說第幾條）、新檔名有 Windows 不能用的字元或保留名稱（`CON`、`NUL`…）、
  以空白或句點結尾、同一批裡新檔名重複、目標檔名已經有別的檔案。沒有命中規則的檔案以灰字顯示，可以勾「只顯示會改名的」。
- **安全的套用**：先把整批改成暫時名稱，再改成目標名稱，所以互換（A↔B）、一串（1→2、2→3）都不會撞名；
  任何一個檔案失敗（例如被別的程式開著），整批自動改回原名。
- **↩ 復原上次改名**：上一批的對照存在 `data\last_batch.json`，關掉程式再開也能復原。

## 使用方式

以下在 PersonalToolZoo repo 根目錄執行：

```powershell
.\tools\file-renamer\run.bat                 # 從原始碼執行（自動用 tools\file-renamer\.venv，沒有就建好）
.\scripts\build.ps1 file-renamer             # 打包成 exe
```

1. 把要整理的資料夾拖進視窗（或按「＋ 加入資料夾」）
2. 在規則清單新增規則、填「尋找」「取代成」，看預覽的「新檔名」欄
3. 確認沒有紅字後按「套用改名」；不滿意就按「↩ 復原上次改名」

## 交接

| 項目 | 內容 |
|---|---|
| 入口 | `main.py`（畫面）；改名邏輯全部在 `renamer.py`（規則、掃描、預覽、兩段式套用、復原、存檔），可以單獨測試 |
| 版本號 | `version.py` 的 `__version__` → exe 檔名 `FileRenamer(vX.Y.Z).exe`、視窗標題 `File Renamer vX.Y.Z` |
| 環境 | 有第三方套件 → `tools\file-renamer\.venv` |
| 依賴 | `tkinterdnd2<1`（拖放） |
| 共用程式 | `libs/toolzoo/appdirs`（資料放哪裡）——tool.json 的 `pathex` 指向 `../../libs`，進入點開頭也把它加進 `sys.path` |
| 資料 | 工具旁邊的 `data\`：`settings.json`（目前的規則與選項）、`presets.json`（規則組）、`last_batch.json`（上一批改名，給復原用） |
| 打包額外內容 | `icon` 與 `include`: `assets/FileRenamer.ico`；`collect_all`: `tkinterdnd2`（tkdnd 的 DLL） |
| 測試 | `.\tools\file-renamer\.venv\Scripts\python.exe -m unittest discover -s tools\file-renamer\tests -v`（16 個：規則、衝突、互換與連鎖改名、失敗整批還原、掃描、存檔，以及畫面走一遍到重開後復原） |
| Release tag | `FileRenamer_vX.Y.Z` |

### 注意事項

- 2026-10-23 重寫：舊版只有一條規則、只能一個一個加檔案、規則會改到副檔名、連鎖改名會撞名、關掉就不能復原。
  畫面與邏輯分開（`renamer.py`），新增功能請先在 `tests/test_renamer.py` 加測試。
- 舊版（`Python Projects\。File Renamer`）會多開一個空白視窗：它的 `FileRenamerApp` 忽略傳進來的 root、
  自己又建了一個 `TkinterDnD.Tk()`。現在只有一個視窗。
- 圖示放在 `assets\`；`data\` 只放執行時產生的資料（不進版控）。
