# CryptoTool Pro 介面規格（新主視窗，0.4.0）

> **這份規格對應的畫面還沒有人實際看過。** 程式是照這份寫的，邏輯有單元測試，視圖的程式碼在假的
> tkinter 上整個跑過一遍（`tests/test_gui_view_headless.py`），但顏色、間距、字體好不好看、捲動順不順，
> 只有在真的電腦上執行 `tools\encrypter\run.bat` 才看得出來。驗收清單在最後一節。

對應程式：`crypto_tool/gui/app.py`（視圖）、`gui/logic.py`（邏輯，不碰 tkinter）、
`gui/texts.py`（全部文案）、`gui/theme.py`（主題名稱、顏色、字體、尺寸）。實際的加解密在 `sealed/workflow.py`（跟命令列同一套）。
改文案只改 `texts.py`；改顏色與尺寸只改 `theme.py`。

## 設計原則

1. **一個畫面只做一件事，由上往下幾步**：選東西 → 選格式 → 誰可以打開 → 存哪裡 → 一顆主要按鈕。
2. **簡單模式是預設**：不必懂加密法就能用。只有兩種公開格式可選：簡單模式（age）與 PGP 模式（OpenPGP）。
3. **主視窗沒有 Mixture、迭代次數、XOR、Base64 這些舊選項**。舊功能全部在「關於 → 開啟舊版工具」。
   （「PGP 模式」是新的標準 OpenPGP，跟舊版那個不是 OpenPGP 的 PGP 實驗無關。）
4. **說人話**：成功講存在哪裡、誰打得開、接下來要注意什麼；失敗講原因、怎麼辦、以及「沒有產生任何輸出檔」。
   不顯示程式的例外文字，不顯示英文錯誤。
5. **不幫使用者做危險的事**：不覆蓋既有檔案（要自己勾）、不刪原檔、私鑰永遠不顯示（只顯示公鑰）。
6. **不卡畫面**：加解密、產生金鑰（算 scrypt、呼叫 gpg）、找 gpg 都在背景執行緒；按鈕變灰直到做完。

## 視窗

| 項目 | 值 |
|---|---|
| 標題 | `CryptoTool Pro v<版本>`（版本讀 `_version.py`） |
| 起始大小／最小 | 900 × 780／760 × 600，開在螢幕中間偏上；每個分頁的內容可以上下捲動（滑鼠滾輪） |
| 主題 | ttkbootstrap 內建 `flatly`（淺色，預設）與 `darkly`（深色）；標題列右邊一顆按鈕切換 |
| 字體 | Microsoft JhengHei UI：內文 10、小字 9、區塊標題 10 粗、主按鈕 11 粗、視窗標題 16 粗、拖放區 12 |
| 留白 | 分頁內容左右 18、區塊之間 10 |

結構（由上到下）：

```
┌ CryptoTool Pro   用公開標準格式把檔案鎖起來：別的電腦用 age 或 PGP 也打得開   [深色] ┐
├ [ 加密 ][ 解密 ][ 金鑰 ][ 關於 ] ─────────────────────────────────────────────┤
│  （分頁內容，可捲動）                                                           │
├──────────────────────────────────────────────────────────────────────────────┤
└ 準備好了                                                               v0.4.0 ┘
```

## 分頁：加密

```
┌ ① 要加密什麼 ──────────────────────────────────────────────┐
│ ┌──────────────────────────────────────────────────────┐ │
│ │       把檔案或資料夾拖到這裡（可以一次好幾個）          │ │  ← 拖放區，點一下也能選檔案
│ └──────────────────────────────────────────────────────┘ │
│ [選檔案…] [選資料夾…] [再加一個…] [ 路徑                 ] │
│ 檔案・1.2 MB ／ 資料夾 ／ 3 個項目，會先打包成一個檔再加密   │
└──────────────────────────────────────────────────────────┘
┌ ② 用哪一種格式 ────────────────────────────────────────────┐
│ (●) 簡單模式（age，建議）  ( ) PGP 模式（OpenPGP，需要 gpg） │
│ 公開的 age 格式：任何裝了 age／rage 的電腦也打得開。…        │
└──────────────────────────────────────────────────────────┘
┌ ③ 誰可以打開 ──────────────────────────────────────────────┐
│ [ ] 密語（自己記的一句話）                                   │
│     密語 [••••••] [ ] 顯示 / 再輸入一次 [••••••] / 強度提示   │
│ [✓] 金鑰（公鑰）                                            │
│     公鑰 age1… [            ] [加入] [加入檔案…] [清除]       │
│     已加入 2 把：age1abcd…、bob.txt                          │
│     貼上對方給你的 age1… 公鑰，或選公鑰清單檔／自己的身分檔。   │
│     [✓] 也讓萬用鎖打得開 （萬用鎖：age1xyz…）                │
└──────────────────────────────────────────────────────────┘
┌ ④ 存到哪裡 ────────────────────────────────────────────────┐
│ [ 自動填好：原名稱.age／.tar.age／.gpg／.asc     ] [另存…]   │
└──────────────────────────────────────────────────────────┘
▸ 進階設定（存成文字形式、輸出檔已存在時直接覆蓋）
[  加密  ] [██████████░░░░░░░░░░░░] 42%（5.1 MB／12.0 MB）
加密完成 ／ 存在：… ／ 格式：age（簡單模式）／ 可以打開的鑰匙：2 把金鑰（含萬用鎖）／ …
```

行為：

- 可以拖進或選好幾個東西；多個或資料夾會先打包成 tar 再加密。輸出位置自動填（單一檔案 `名稱.age`、資料夾 `名稱.tar.age`、
  多個 `bundle.tar.age`；PGP 模式 `.gpg`，文字形式 `.asc`）；使用者自己改過就不再自動覆蓋。
- 切換模式：說明換掉、公鑰清單清空（兩種公鑰不通用）、萬用鎖改成該模式的設定。找不到 gpg 時 PGP 模式的說明改成
  「這台電腦找不到 gpg…」，按加密時列在「還差一點」。
- 「也讓萬用鎖打得開」：有設定萬用鎖（`.env` 或金鑰分頁）時**預設勾選**；沒設定時灰掉並說「到金鑰分頁設定」。
- 簡單模式勾了密語又有金鑰（或萬用鎖）：按下去時在「還差一點」說明 age 規格不允許，建議改用 PGP 模式或全部用金鑰。
- 公鑰欄打了東西但沒按「加入」，按加密時照樣算進去。
- 按「加密」：先檢查，缺什麼就在結果區列出來（標題「還差一點」），不開始。開始後按鈕變灰、狀態列「加密中…」，背景執行，進度條跟著跑。
- 成功：綠色「加密完成」＋存在哪裡＋格式＋誰打得開＋（資料夾時）幾個檔案＋「原本的檔案沒有被動到…」＋「鑰匙或密語不見就打不開…」；密語欄位清空。
- 失敗：紅色標題（見下表）＋原因＋怎麼辦＋「沒有產生任何輸出檔。」

## 分頁：解密

- ① 只有「選檔案…」；拖放區文字「把加密檔（.age／.gpg／.asc）拖到這裡」。選好後說明列顯示**這一層要什麼**（不需要鑰匙）：
  `age・金鑰 2 把・1.2 MB`、`age・密語・…`、`OpenPGP・收件人 1234ABCD…・也可用密語・…`、
  `ISD2 預覽格式（已停用）・用金鑰檔加密・…`。選到舊版 `.isd`：說明「要用關於分頁裡的舊版工具」＋「開啟舊版工具…」按鈕。
- ② 用什麼開：鑰匙檔清單（age 身分檔或 OpenPGP 私鑰；`.env` 設定的預設鑰匙自動帶入；可拖放、可加好幾個）、
  「檔案的密語」「鑰匙檔的密語」兩欄（各自什麼時候要填寫在下面的小字）、「一路解到底」勾選框。
- ③ 自動填成去掉 `.age`／`.gpg`／`.asc` 的名稱（資料夾再去掉 `.tar`）；內容是資料夾時會還原成資料夾。
- 進階設定：「內容是資料夾時不解開，存成 .tar 檔」＋「輸出檔已存在時直接覆蓋」（已存在且非空的資料夾永遠不覆蓋）。
- 成功：綠色「解密完成」＋存在哪裡＋格式＋（用萬用鎖時）「用的是萬用鎖。」＋（ISD2 預覽檔時）建議重新加密。
- 一路解到底：解到底是綠色並寫「一共解開 N 層」；停在某層是**黃色「解開了一部分」**，逐條列出「第 N 層需要別的鑰匙：路徑（金鑰 2 把）」。
- 主按鈕「解密」（綠色）。成功後兩個密語欄位清空。

## 分頁：金鑰

- 開頭一段說明：公鑰與私鑰的差別、私鑰一定要備份、萬用鎖是唯一的後路。
- **產生簡單模式的金鑰（age）**：`身分檔存成 [路徑] [另存…]`（建議檔名 `.decryption_code.env`）、
  「用密語保護私鑰（建議）」密語＋再輸入一次（可留空）、「設成這台電腦預設的解密鑰匙（只把路徑寫進 .env）」→「產生」。
  背景執行；成功後顯示路徑、**公鑰**、有沒有密語保護、備份提醒。檔案已存在時**不會覆蓋**。
- **產生 PGP 金鑰對（OpenPGP）**：`檔名開頭 [路徑]`、名稱、密語（可留空）→「產生金鑰對」（呼叫 gpg，要幾秒鐘）→ 公鑰與私鑰檔的路徑、指紋。
- **萬用鎖**：說明一段；`簡單模式的萬用鎖公鑰 [age1…] [從身分檔讀…]`、`PGP 模式的萬用鎖公鑰檔 [路徑] [加入檔案…]`、「儲存」。
  寫進 `.env`（只改那一行），格式不對就不寫；兩欄都空＝清除。存好後加密頁的萬用鎖勾選立刻更新。
- **檢查一個鑰匙檔**：`[路徑] [加入檔案…] [檢查]` → age 身分檔（顯示公鑰）、有密語保護的身分檔、公鑰清單、OpenPGP 私鑰／公鑰、
  ISD2 預覽格式（已停用）的舊金鑰檔（顯示指紋）。**不顯示私鑰內容。**

## 分頁：關於

- 名稱＋版本、一句話說明、幾點說明（兩種公開格式、age 是自寫實作且通過官方向量但未審閱、萬用鎖、失敗行為、資料夾、命令列、這版不簽章）。
- 一個框「舊版工具（實驗性）」：說明＋「開啟舊版工具…」按鈕。按下去畫面切成深色，另外開一個視窗，
  裡面是以前的 File／Text／Mixture／Large File 四個分頁，最上面有一條黃色警告。缺少舊格式需要的套件時，在框內用一句話說明，不會當掉。

## 錯誤訊息對照

結果區的標題由錯誤代碼決定，內文用錯誤本身帶的「原因」與「怎麼辦」（跟命令列是同一套句子）：

| 代碼 | 標題 | 顏色 |
|---|---|---|
| `wrong_key` | 鑰匙或密語不對 | 紅 |
| `corrupt` | 這個加密檔壞了或被改過 | 紅 |
| `output_exists` | 那個位置已經有東西了 | 黃 |
| `input_missing` | 找不到檔案 | 紅 |
| `key_missing` | 找不到鑰匙 | 紅 |
| `bad_key_format` | 鑰匙的種類或格式不對 | 紅 |
| `unsupported_format` | 這不是這個工具認得的加密檔 | 紅 |
| `legacy_format` | 這是舊版格式（.isd） | 黃 |
| `unsafe_archive` | 這個加密檔的內容不安全，已停止 | 紅 |
| `dependency_missing` | 程式的環境沒有裝好 | 紅 |
| `io_error` | 讀寫檔案失敗 | 紅 |
| `bad_input` | 這樣沒辦法做 | 黃 |
| `internal_bug` | 程式出了沒預期到的錯 | 紅 |

## 還沒做的

- 主題的選擇不會記住，每次開都是淺色。
- 進行中不能取消。
- 視窗裡沒有 `rewrap`／`rekey`（命令列有）；沒有「加密一段文字」（舊版的 Text 分頁還在舊版工具裡）。
- 公鑰清單只能整個清除，不能刪單一項。
- 自訂色票（品牌色）沒做，先用內建主題。

## 驗收清單（要在真的電腦上看）

執行 `tools\encrypter\run.bat`，逐項確認：

- [ ] 視窗開得起來，四個分頁的字沒有被切掉，中文字體正常；視窗縮小時可以用滾輪捲到每個元件。
- [ ] 金鑰分頁產生一把 age 身分檔（有密語保護）：顯示公鑰，按鈕在產生時變灰；勾「設成預設」後解密頁的鑰匙清單自動有它。
- [ ] 金鑰分頁產生第二把當萬用鎖，用「從身分檔讀…」填入並儲存：加密頁的「也讓萬用鎖打得開」變成可勾且已勾。
- [ ] 把一個檔案拖到加密分頁：路徑、說明、輸出位置都自動出現；拖到上面時底色有變。貼上第一把的公鑰→加密：結果寫「2 把金鑰（含萬用鎖）」。
- [ ] 解密分頁選剛剛的 `.age`：說明寫「age・金鑰 2 把」；用第一把（輸入鑰匙檔的密語）解得開；換成萬用鎖也解得開並寫「用的是萬用鎖」。
- [ ] 加密一個資料夾＋另一個檔案（再加一個…）再解開，內容一樣。
- [ ] 簡單模式同時勾密語與金鑰：按加密會看到建議改用 PGP 模式的說明。
- [ ] 有 gpg 的電腦：切到 PGP 模式產生金鑰對、加密給它、解開；沒有 gpg 的電腦：PGP 模式顯示找不到 gpg。
- [ ] 做一個兩層的檔（內層只給另一把鑰匙）：勾「一路解到底」只用外層的鑰匙解，看到黃色「第 2 層需要別的鑰匙」。
- [ ] 打錯密語是紅色「鑰匙或密語不對」，而且沒有留下輸出檔。
- [ ] 右上角切深色／淺色：拖放區、捲動區的底色、文字都看得清楚。
- [ ] 關於 → 開啟舊版工具：舊的四個分頁出得來，能解開一個以前的 `.isd`。
