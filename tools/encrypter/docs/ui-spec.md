# CryptoTool Pro 介面規格（新主視窗）

> **這份規格對應的畫面還沒有人實際看過。** 程式是照這份寫的，邏輯有單元測試，視圖的程式碼在假的
> tkinter 上整個跑過一遍（`tests/test_gui_view_headless.py`），但顏色、間距、字體好不好看，
> 只有在真的電腦上執行 `tools\encrypter\run.bat` 才看得出來。驗收清單在最後一節。

對應程式：`crypto_tool/gui/app.py`（視圖）、`gui/logic.py`（邏輯，不碰 tkinter）、
`gui/texts.py`（全部文案）、`gui/theme.py`（主題名稱、顏色、字體、尺寸）。
改文案只改 `texts.py`；改顏色與尺寸只改 `theme.py`。

## 設計原則

1. **一個畫面只做一件事，由上往下三步**：① 選東西 → ② 選鎖 → ③ 存哪裡 → 一顆主要按鈕。
2. **簡單模式是預設**：不必懂加密法就能用。能選的技術細節只有「加密法」一項，收在「進階設定」裡，預設收合。
3. **主視窗沒有 Mixture、迭代次數、XOR、Base64、PGP 這些選項**。舊功能全部在「關於 → 開啟舊版工具」。
4. **說人話**：成功講存在哪裡、接下來要注意什麼；失敗講原因、怎麼辦、以及「沒有產生任何輸出檔」。
   不顯示程式的例外文字，不顯示英文錯誤。
5. **不幫使用者做危險的事**：不覆蓋既有檔案（要自己勾）、不刪原檔、金鑰內容永遠不顯示。

## 視窗

| 項目 | 值 |
|---|---|
| 標題 | `CryptoTool Pro v<版本>`（版本讀 `_version.py`） |
| 起始大小／最小 | 860 × 720／720 × 620，開在螢幕中間偏上 |
| 主題 | ttkbootstrap 內建 `flatly`（淺色，預設）與 `darkly`（深色）；標題列右邊一顆按鈕切換 |
| 字體 | Microsoft JhengHei UI：內文 10、小字 9、區塊標題 10 粗、主按鈕 11 粗、視窗標題 16 粗、拖放區 12 |
| 留白 | 分頁內容左右 18、區塊之間 10 |

結構（由上到下）：

```
┌ CryptoTool Pro   把檔案鎖起來，只有你的金鑰或密語打得開          [深色] ┐
├ [ 加密 ][ 解密 ][ 金鑰 ][ 關於 ] ─────────────────────────────────────┤
│  （分頁內容）                                                          │
├───────────────────────────────────────────────────────────────────────┤
└ 準備好了                                                       v0.3.0 ┘
```

## 分頁：加密

```
┌ ① 要加密什麼 ──────────────────────────────────────────────┐
│ ┌──────────────────────────────────────────────────────┐ │
│ │            把檔案或資料夾拖到這裡                      │ │  ← 拖放區，點一下也能選檔案
│ └──────────────────────────────────────────────────────┘ │
│ [選檔案…] [選資料夾…] [ 路徑輸入框                      ] │
│ 檔案・1.2 MB                                              │  ← 一行說明（小字）
└──────────────────────────────────────────────────────────┘
┌ ② 用什麼鎖 ────────────────────────────────────────────────┐
│ (●) 密語（自己記的一句話）   ( ) 金鑰檔                     │
│ 密語        [••••••••••••••••••••          ] [ ] 顯示      │
│ 再輸入一次  [••••••••••••••••••••          ]               │
│             還可以，再長一點更好                           │  ← 強度提示，邊打邊更新
└──────────────────────────────────────────────────────────┘
┌ ③ 存到哪裡 ────────────────────────────────────────────────┐
│ [ 自動填好：原名稱.isd2                        ] [另存…]   │
└──────────────────────────────────────────────────────────┘
▸ 進階設定
[  加密  ] [██████████░░░░░░░░░░░░░░░░] 42%（5.1 MB／12.0 MB）
加密完成                                                       ← 結果區
存在：…
```

行為：

- 拖進多個東西只取第一個。選好輸入後，輸出位置自動填成「原名稱 + `.isd2`」；使用者自己改過就不再自動覆蓋。
- 選「金鑰檔」時，② 換成：`金鑰檔 [路徑] [瀏覽…]`（路徑框也能拖放）＋小字「還沒有金鑰檔？到「金鑰」分頁產生一把。」
- 進階設定展開後：加密法二選一（AES-256-GCM 預設／ChaCha20-Poly1305）＋小字說明＋「輸出檔已存在時直接覆蓋」。
- 按「加密」：先檢查，缺什麼就在結果區列出來（標題「還差一點」），不開始。
  開始後按鈕變灰、狀態列顯示「加密中…」，在背景執行，進度條跟著跑；視窗不會卡住。
- 成功：結果區綠色「加密完成」＋存在哪裡＋（資料夾時）幾個檔案＋「原本的檔案沒有被動到…」＋
  「金鑰或密語不見就打不開。請在這台電腦以外的地方另外留一份。」；密語欄位清空。
- 失敗：紅色標題（見下表）＋原因＋怎麼辦＋「沒有產生任何輸出檔。」

## 分頁：解密

版面跟加密一樣，差別：

- ① 只有「選檔案…」；拖放區文字「把 .isd2 加密檔拖到這裡」。選好後說明列顯示
  `AES-256-GCM・用密語加密・內容是一個檔案・1.2 MB`，並且 **② 自動切到當初用的那一種**（密語或金鑰檔）。
- 選到舊版 `.isd`：說明列顯示「舊版 .isd 格式：要用「關於」分頁裡的舊版工具才能解。」，下面出現「開啟舊版工具…」按鈕。
- ② 密語只輸入一次，沒有強度提示。
- ③ 自動填成去掉 `.isd2` 的名稱；內容是資料夾時會還原成資料夾。
- 進階設定：「內容是資料夾時不解開，存成 .tar 檔」＋「輸出檔已存在時直接覆蓋」（已存在且非空的資料夾永遠不覆蓋）。
- 主按鈕「解密」（綠色）。

## 分頁：金鑰

- 開頭一段說明：金鑰檔是什麼、為什麼一定要備份。
- **產生新的金鑰檔**：`存成 [路徑] [另存…]`（建議檔名 `.decryption_code.env`）→「產生金鑰檔」。
  成功後顯示：已產生的路徑、金鑰指紋（12 個字元，用來核對備份是不是同一把）、以及一段備份提醒：
  現在就複製一份到這台電腦以外的地方；不要跟加密檔放在同一個資料夾或同一個雲端。
  檔案已存在時**不會覆蓋**（視窗裡沒有覆蓋的選項，避免把還在用的金鑰洗掉）。
- **檢查一個金鑰檔**：`[路徑] [瀏覽…] [檢查]` → 只回答「可以用，是 32 bytes 金鑰，指紋是…」或
  「可以用，裡面放的是密語」或哪裡不對。**不顯示金鑰內容。**

## 分頁：關於

- 名稱＋版本、一句話說明、四點做法說明（加密法、副檔名與失敗行為、資料夾、命令列）。
- 一個框「舊版工具（實驗性）」：說明＋「開啟舊版工具…」按鈕。按下去畫面切成深色，
  另外開一個視窗，裡面是以前的 File／Text／Mixture／Large File 四個分頁，最上面有一條黃色警告。
  缺少舊格式需要的套件時，在框內用一句話說明，不會當掉。

## 錯誤訊息對照

結果區的標題由錯誤代碼決定，內文用錯誤本身帶的「原因」與「怎麼辦」（跟命令列是同一套句子）：

| 代碼 | 標題 | 顏色 |
|---|---|---|
| `wrong_key` | 金鑰或密語不對 | 紅 |
| `corrupt` | 這個加密檔壞了或被改過 | 紅 |
| `output_exists` | 那個位置已經有東西了 | 黃 |
| `input_missing` | 找不到檔案 | 紅 |
| `key_missing` | 找不到金鑰 | 紅 |
| `bad_key_format` | 金鑰的種類或格式不對 | 紅 |
| `unsupported_format` | 這不是這個工具的加密檔 | 紅 |
| `legacy_format` | 這是舊版格式（.isd） | 黃 |
| `unsafe_archive` | 這個加密檔的內容不安全，已停止 | 紅 |
| `dependency_missing` | 程式的環境沒有裝好 | 紅 |
| `io_error` | 讀寫檔案失敗 | 紅 |
| `bad_input` | 這樣沒辦法做 | 黃 |
| `internal_bug` | 程式出了沒預期到的錯 | 紅 |

## 還沒做的

- 主題的選擇不會記住，每次開都是淺色（要記住得接 `libs/toolzoo/appdirs`，會動到打包設定）。
- 進行中不能取消。
- 視窗裡沒有「加密一段文字」；舊版的 Text 分頁還在舊版工具裡。

## 驗收清單（要在真的電腦上看）

執行 `tools\encrypter\run.bat`，逐項確認：

- [ ] 視窗開得起來，四個分頁的字沒有被切掉，中文字體正常。
- [ ] 把一個檔案拖到加密分頁的拖放區：路徑、說明、輸出位置都自動出現；拖到上面時底色有變。
- [ ] 用密語加密一個檔案：強度提示會變色；進度條會動；結果是綠色、文字讀得懂。
- [ ] 到解密分頁選剛剛的 `.isd2`：自動切到「密語」；打錯密語是紅色「金鑰或密語不對」；打對可以解開。
- [ ] 加密一個資料夾再解開，內容一樣。
- [ ] 金鑰分頁產生金鑰檔，再用它加解密一次。
- [ ] 右上角切深色／淺色：拖放區、文字都看得清楚。
- [ ] 視窗縮到最小時沒有元件消失；展開進階設定後按鈕還看得到。
- [ ] 關於 → 開啟舊版工具：舊的四個分頁出得來，能解開一個以前的 `.isd`。
